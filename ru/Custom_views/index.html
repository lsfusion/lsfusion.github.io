Пользовательские представления

Пользовательское представление — часть дизайна формы или дизайна навигатора, которую вместо платформы рисует клиентский код: собственный код приложения на JavaScript, выполняемый в веб-клиенте. В десктоп-клиенте на её месте используется стандартное представление платформы.

Виды пользовательских представлений​

Клиентский код может рисовать следующие части интерфейса:

Часть интерфейсаКлиентский код
Контейнер дизайна формы со всем, что внутриКомпонент React
Таблица дерева, тулбар, управляющие элементы фильтров, группа фильтров или фильтр по свойствуКомпонент React
Строки группы объектов — пользовательский вид списка наряду с таблицей, сводной таблицей, картой и календарёмКомпонент React или функция JavaScript
Значение свойства в ячейке таблицы или на панелиКомпонент React или функция JavaScript
Редактор значения при изменении свойства или вводе значения — дополнение стандартного поля ввода, отдельное окно или замена содержимого ячейкиФункция JavaScript
Окно навигатора, окно форм, окно сообщений или расположение окон на рабочем столеКомпонент React, только в настольном веб-клиенте

Контейнер формы можно также разметить HTML-шаблоном: дочерние компоненты в отведённые им места помещает платформа. Такой шаблон может задавать и расположение элементов окна навигатора.

Состояние формы и его изменение​

Объекты формы, текущие объекты групп, фильтры, сортировки, значения свойств и сессия изменений остаются у платформы. Клиентский код получает данные для той части формы, которую рисует: прочитанные наборы объектов, текущие объекты и значения свойств. Он может использовать и заданные дизайном заголовки, цвета и доступность свойств.

Компонент React также получает варианты свойства, показанного как элемент выбора, и может запросить у сервера асинхронный список значений свойства. Изменения, сделанные обработчиком периодического события формы, поступают в пользовательское представление так же, как любые другие изменения.

Клиентский код меняет состояние формы так же, как пользователь: выбирает текущий объект, меняет значение свойства, выполняет нарисованное на форме действие. Компонент React может также менять сортировки и пользовательские фильтры таблицы, выбирать фильтр в группе фильтров, выполнять действия тулбара и раскрывать или сворачивать узлы дерева. Когда компонент рисует строки группы объектов вне дерева, он может читать и менять то же выделение строк и колонок, о котором сообщают свойства выделения. Изменение свойства выполняет его событие изменения, а переданное значение подставляется вместо ввода пользователя в запрос значения. Источник такого изменения — пользовательский клиентский код (CUSTOM). Изменения проходят обычные проверки правки формы и не требуют доступа к внешнему API.

Вызовы сервера​

Помимо правки формы, клиентский код может вызывать на сервере действия и изменять свойства по имени, а также выполнять код на языке lsFusion. На форме эти вызовы выполняются в её сессии: изменение видно следующим вызовам и сохраняется вместе с изменениями формы. В навигаторе каждый вызов выполняется в новой сессии.

По умолчанию такие вызовы проверяются как доступ из внешней системы: разрешены действия и свойства, открытые внешнему API, а также вызовы пользователя, который может выполнять код в интерпретаторе. Форма может дополнительно разрешить своему клиентскому коду вызовы отдельных действий и свойств. Выполнение произвольного кода остаётся под проверкой доступа к API.

Компоненты платформы внутри​

Компонент React, рисующий контейнер, может оставить часть его содержимого платформе. Тогда платформа рисует эти компоненты, а компонент React размещает их внутри своего представления. Дочерний компонент с собственным представлением — стандартным или другим пользовательским — рисуется этим представлением.

Скрытое пользовательское представление​

Контейнер с пользовательским представлением скрывается так же, как любой компонент дизайна: например, на невыбранной вкладке или внутри свёрнутого контейнера. С помощью действий формы компонент может сам выбирать вкладки, сворачивать и разворачивать контейнеры, в которых он находится. Пока форма скрывает контейнер, сервер не читает то, что рисует его представление, если те же данные не нужны показанной части формы. Форма, которая целиком не видна на экране, читается как обычно.

Компоненты платформы, которые представление React не размещает, не читаются, если те же данные не нужны показанной части формы. Их заголовки, изображения и комментарии продолжают читаться, только если эти подписи отображаются вне скрытого содержимого. Подписи действия и свойства в списке следуют видимости самого действия или свойства. Контейнер, который компонент React рисует сам, сервер считает показанным, пока компонент не сообщит, что скрывает его.

Клавиши и редактирование​

Привязки клавиш и мыши свойств, действий и групп фильтров, которые рисует компонент React, обрабатывает платформа с учётом режимов этих привязок. Исключение — привязки, которым нужна ячейка платформы для ввода значения. Клавиши стандартной таблицы над строками, которые рисует компонент, не действуют.

Когда пользователь вводит текст в поле клиентского кода, код сообщает форме о редактировании. Тогда клавиши подтверждения и отмены, а также привязки, не работающие при редактировании, не перехватывают ввод в этом поле. Это сообщение само по себе не начинает изменение свойства и не сохраняет введённое значение.

Модули клиентского кода​

Клиентский код хранится в проекте файлами. Они могут собираться при сборке проекта или использоваться без сборки и загружаются в веб-клиент при открытии страницы.

Язык​

Функция JavaScript, указанная в CUSTOM 'itemCards', рисует строки группы товаров.

HTML-шаблон задаёт места для дочерних компонентов контейнера формы.

React​

  • Выбор компонента объясняет, как задать в дизайне компонент React, который будет рисовать контейнер формы.
  • Собственное представление компонента показывает, как задать отдельный компонент React для отрисовки таблицы дерева, тулбара, управляющих элементов фильтров, группы фильтров или фильтра по свойству.
  • Компонент React в CUSTOM показывает, как компонент React рисует строки группы объектов в пользовательском представлении списка или значение свойства.
  • Проекция формы описывает состояние части формы, которую рисует компонент React, в том числе группы объектов с их строками и текущими объектами, значения свойств и варианты свойств, показанных как элементы выбора.
  • Поиск значений показывает, как компонент React запрашивает у сервера асинхронный список значений свойства.
  • Обновление по расписанию объясняет, как изменения, сделанные обработчиком SCHEDULE, поступают в компонент React так же, как любые другие изменения.
  • Контроллер представления React описывает, как компонент React меняет текущие объекты и значения свойств и выполняет действия формы.
  • Изменение текущего объекта и значений свойств объясняет, как компонент React вызывает обработку событий изменения свойств с источником CUSTOM и передаёт в запрос значение вместо ввода пользователя.
  • Деревья показывают, как компонент React рисует дерево объектов, раскрывает и сворачивает его узлы.
  • Сортировки показывают, как компонент React рисует и меняет сортировки группы объектов.
  • Фильтры и тулбар описывают, как компонент React рисует и меняет пользовательские фильтры и группы фильтров, рисует тулбар и выполняет его действия.
  • Выделенные строки и колонки описывают, как компонент React, рисующий строки группы объектов вне дерева, читает и меняет их выделение так же, как таблица платформы.
  • Контроллеры формы и навигатора дают компоненту React вызовы сервера, а на форме — изменение того, что рисуется в других контейнерах, и объединение изменений в пакет.
  • Размещение компонентов платформы описывает, как компонент React, рисующий контейнер, размещает дочерние компоненты, которые рисует платформа.
  • Скрытое представление описывает, как невыбранная вкладка или свёрнутый контейнер скрывает то, что рисует компонент React, и как компонент с помощью действий формы выбирает вкладки, сворачивает и разворачивает контейнеры, в которых находится.
  • Клавиши и привязки мыши свойств, действий и групп фильтров, которые рисует компонент React, обрабатывает платформа, кроме привязок, которым нужна ячейка платформы.
  • Клиентские модули JavaScript описывают хранение, сборку, загрузку и поиск по имени компонентов React.

Примеры​

В примерах предполагается, что объявлены класс Item со свойством name[Item] и класс Order со свойствами number[Order], date[Order], sum[Order]. Функция JavaScript itemCards и компонент React OrderBoard загружены в веб-клиент.

Функция JavaScript рисует строки группы товаров вместо стандартной таблицы:

FORM items
    OBJECTS i = Item CUSTOM 'itemCards'
    PROPERTIES(i) name
;

Компонент React рисует весь контейнер группы заказов:

FORM orders 'Orders'
    OBJECTS o = Order
    PROPERTIES(o) READONLY number, date, sum
;

DESIGN orders {
    BOX(o) {
        custom = 'OrderBoard';
    }
}

Компонент OrderBoard рисует по строке с номером и суммой каждого прочитанного заказа:

export function OrderBoard(props) {
    return <ul className="order-board">
        {props.data.o.list.map(r => <li key={r.key}>{r.number.value}: {r.sum.value}</li>)}
    </ul>;
}
