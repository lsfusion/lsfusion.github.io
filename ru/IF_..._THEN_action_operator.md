# Оператор IF ... THEN

Оператор `IF ... THEN` создает [действие](/ru/Actions.md), реализующее [ветвление](/ru/Branching_CASE_IF_MULTI.md#single) с одним условием (одиночная форма).

### Синтаксис[​](#синтаксис "Прямая ссылка на этот заголовок")

```
IF condition 
THEN action
[ELSE alternativeAction]
```

### Описание[​](#описание "Прямая ссылка на этот заголовок")

Оператор `IF ... THEN` создает действие, реализующее ветвление с одним условием. При выполнении этого действия проверяется условие: если оно выполняется, вызывается действие, указанное после ключевого слова `THEN`. Если оно не выполняется, вызывается действие, указанное после ключевого слова `ELSE` (если этот блок задан).

Ветка `ELSE` присоединяется к ближайшему предшествующему оператору, который допускает ее и еще ее не имеет. Если действие после `THEN` записано без [фигурных скобок](/ru/Braces_operator.md) и само является оператором, синтаксис которого заканчивается необязательной веткой `ELSE` — [`ASK`](/ru/ASK_operator.md), [`INPUT`](/ru/INPUT_operator.md), [`DIALOG`](/ru/DIALOG_operator.md) и [`IMPORT`](/ru/IMPORT_operator.md) при записи с `DO`, [`FOR`](/ru/FOR_operator.md), [`REQUEST`](/ru/REQUEST_operator.md), [`CASE`](/ru/CASE_action_operator.md) или другой `IF ... THEN`, — следующий за ним `ELSE` становится веткой этого оператора, а не данного. Ошибка или предупреждение при этом не выдаются, а при невыполнении условия не выполняется ничего. Чтобы `ELSE` относился к оператору `IF ... THEN`, действие после `THEN` нужно заключить в фигурные скобки.

### Параметры[​](#параметры "Прямая ссылка на этот заголовок")

* `condition`

  [Выражение](/ru/Expression.md), задающее условие. Если значение выражения не равняется `NULL`, то условие выполняется и вызывается действие указанное после ключевого слова `THEN`.

* `action`

  [Контекстно-зависимый оператор](/ru/Action_operators.md#contextdependent), описывающий действие, которое будет вызвано при выполнении условия.

* `alternativeAction`

  Контекстно-зависимый оператор, описывающий действие, которое будет вызвано, если условие не выполняется.

### Примеры[​](#примеры "Прямая ссылка на этот заголовок")

```
// Действие, сравнивающее значение свойства count с числом 3 и выдающее пользователю сообщение
moreThan3(obj)  {
    IF count(obj) > 3 THEN
        MESSAGE '>3';
    ELSE
        MESSAGE '<=3';
}

checkNullName (Store st) {
    IF NOT name(st) THEN
        MESSAGE 'Name is null';
}

// ELSE относится к ASK (ветка отмены), а не к IF: при confirm() = NULL не выполняется ничего
sendOrAsk (Order o)  {
    IF confirm() THEN
        ASK 'Отправить заказ?' DO send(o);
    ELSE
        send(o);
}

// фигурные скобки привязывают ELSE к IF
sendOrAskFixed (Order o)  {
    IF confirm() THEN {
        ASK 'Отправить заказ?' DO send(o);
    } ELSE
        send(o);
}
```
