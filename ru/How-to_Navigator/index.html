How-to: Навигатор

Пример 1​

Условие​

Есть формы со списком книг и категорий.

FORM categories 'Категории';
FORM books 'Книги';

Нужно добавить их в навигатор в новую папку 'Приложение' снизу от основного тулбара.

Решение​

NAVIGATOR {
    NEW FOLDER application 'Приложение' WINDOW toolbar FIRST {
        NEW categories;
        NEW books;
    }
}

Указав WINDOW для элемента application, мы указали, что все его потомки должны отображаться в системном окне toolbar. Именно это делает папку рабочей кнопкой: формы теперь находятся в отдельном окне, поэтому выбор Приложение в верхнем тулбаре раскрывает их в нём. Без WINDOW формы остались бы в одном окне с папкой и постоянно показывались бы рядом с ней, так что выбор папки ничего бы не менял. Это будет выглядеть следующим образом :

Пример 2​

Условие​

Аналогичен Примеру 1

Нужно сделать, чтобы эти же формы были в подпапке 'Справочники'.

Решение​

NAVIGATOR {
    application {
        NEW FOLDER masterData 'Справочники' {
            NEW categories;
            NEW books;
        }
    }
}
