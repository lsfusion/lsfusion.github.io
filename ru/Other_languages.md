# Другие языки

В этом разделе описаны интерфейсы для кода, разметки и стилей на других языках, в том числе для JavaScript, HTML и CSS в клиенте и Java и JRXML на сервере приложений.

* В подразделе [JavaScript](/ru/Client_JavaScript_modules.md) описаны клиентские модули, в которых хранится весь клиентский код, включая компоненты React. Здесь также описаны [функции отображения](/ru/Render_functions.md) и [функции редактирования](/ru/Edit_functions.md) классических пользовательских представлений, [функции, вызываемые через `INTERNAL CLIENT`](/ru/INTERNAL_CLIENT_functions.md), и [контроллеры формы и навигатора](/ru/Form_and_navigator_controllers.md), которые получает любое представление на JavaScript. В его подразделе [React](/ru/React_views.md) описаны вызовы, доступные компоненту React, и данные, которые он получает от формы для отрисовки контейнера или компонента либо от навигатора и окна для отрисовки окна.
* В подразделе [HTML](/ru/HTML_templates.md) описана разметка шаблонов контейнеров формы и окон навигатора.
* В подразделе [CSS](/ru/CSS_view_styles.md) описаны стили форм, элементов навигатора и окон, которые отображает веб-клиент.
* В подразделе [Java](/ru/Java_integration_API.md) описаны классы и методы для обращения к lsFusion из подклассов `InternalAction` и из [компонентов Spring на основе `EventServer`](/ru/Custom_Spring_bean_EventServer.md).
* В подразделе [JRXML](/ru/JRXML_report_templates.md) описаны поля, параметры подотчетов и разметка шаблонов отчетов.
