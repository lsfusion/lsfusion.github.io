# Расширение классов

Техника [расширения](/ru/Extensions.md) классов позволяет разработчику *донаследовать* один [класс](/ru/Classes.md) от другого после его создания. Также при помощи этого механизма можно добавлять в класс дополнительные [статические объекты](/ru/Static_objects.md). Класс, который является потомком `System.StaticObject` только благодаря добавленным так статическим объектам, остаётся им, только пока расширяющий [модуль](/ru/Modules.md) загружен: в проекте, куда этот модуль не входит, у класса нет статических объектов, он не является `System.StaticObject`, и применённые к его объектам свойства статических объектов (`caption[StaticObject]` и остальные) не находятся. Поэтому модуль, применяющий эти свойства к такому классу, зависит от модуля, добавляющего статические объекты, а не только от модуля, объявляющего класс.

Расширение классов вместе с техникой [расширения свойств](/ru/Property_extension.md) и [действий](/ru/Action_extension.md) позволяет:

* Отделять связи между классами в отдельный модуль, тем самым получая более модульную архитектуру.
* Изменять функционал уже существующего модуля без внесения в него каких-либо изменений.
* Объявлять классы в [метакоде](/ru/Metaprogramming.md), определяя наследование класса за его пределами.

### Язык[​](#язык "Прямая ссылка на этот заголовок")

Для того, чтобы расширить класс, используется [инструкция `EXTEND CLASS`](/ru/EXTEND_CLASS_statement.md).

### Примеры[​](#примеры "Прямая ссылка на этот заголовок")

```
CLASS ABSTRACT Shape;
CLASS Box : Shape;

CLASS Quadrilateral;
EXTEND CLASS Box : Quadrilateral; // Добавляем наследование

CLASS ShapeType {
	point 'Точка',
	segment 'Отрезок'
}

EXTEND CLASS ShapeType { // Добавляем статический объект
	circle 'Окружность'
}
```
