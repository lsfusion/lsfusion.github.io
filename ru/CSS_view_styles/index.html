Стили представлений платформы

CSS приложения задаёт стили HTML-элементов, которыми веб-клиент отображает формы, элементы навигатора и окна. В селекторах можно использовать классы, заданные приложением, и атрибуты, которые устанавливает веб-клиент.

Классы CSS​

В строке можно указать несколько имён классов CSS через пробел.

Пары имя=значение можно указать в class, captionClass, valueClass, footerClass и в опциях CLASS из таблицы. Если имя является свойством объекта style элемента, клиент задаёт встроенный стиль, а в остальных случаях задаёт атрибут HTML.

ОпцияHTML-элемент
classЭлемент компонента формы, размещённого в контейнере. Для свойства или действия в панели это компонент, содержащий значение и заголовок. Для свойства в таблице это элемент, в котором отображается значение, то есть сама ячейка или элемент внутри неё. К главному (корневому) контейнеру формы class не применяется. Его можно выбрать по lsfusion-form.
captionClassЭлемент заголовка контейнера, заголовок свойства или действия в панели либо заголовок колонки свойства в таблице.
valueClassЭлемент содержимого контейнера или элемент значения свойства или действия.
footerClassЯчейка подвала колонки свойства.
commentClassЭлемент комментария свойства или действия в панели.
CLASS в NAVIGATORКнопка элемента навигатора в стандартном представлении.
CLASS в WINDOWЭлемент представления окна.
CLASS в PROPERTIESТот же элемент значения, что и у valueClass свойства или действия.

Классы значения свойства​

Значение valueClass или CLASS в PROPERTIES, отличное от NULL, заменяет классы значения по умолчанию, например form-control. Если значение отображается полем ввода, классы добавляются к этому полю. В обычной текстовой ячейке таблицы они добавляются к самой ячейке (td). Группа кнопок или выпадающий список для свойства с малым числом вариантов отображаются внутри элемента значения и сохраняют собственные классы.

Элементы значения свойства​

В таблице указаны HTML-теги, которые платформа по умолчанию выбирает для значений свойств и действий. Опция дизайна tag переопределяет этот выбор.

HTML-тегКогда платформа его выбирает
aЗначение класса LINK или ссылка на файл определённого типа либо свойство, действие изменения которого открывает форму, не меняет данных и не содержит ввода.
inputЗначение, вводимое как текст (строка, число, дата или время), в панели при условиях отображения ячейки значения либо логическое значение.
buttonДействие без вводимого значения, имеющее эффект.
selectЗначение, выбираемое из выпадающего списка, который отображается стандартным элементом выбора по правилам отображения ячейки значения.

В остальных случаях, включая значение, которое рисует функция отображения (custom), у значения нет явного тега. В панели клиент отображает его в div. Элемент значения в таблице описан в разделе классов значения свойства.

Для значения NULL строкового класса в элементе a по умолчанию используется заполнитель Не определено. Явно заданный placeholder имеет приоритет. В стандартных стилях Bootstrap у заполнителя в a цвет ссылки с половинной прозрачностью, а у заполнителя в div — вторичный цвет текста.

Атрибуты для селекторов​

Веб-клиент устанавливает эти атрибуты на создаваемых им элементах. Селектор CSS по атрибуту позволяет обратиться к конкретной форме или компоненту.

АтрибутЭлементЗначение
lsfusion-formКорневой элемент формыКаноническое имя формы, если оно есть.
lsfusion-containerЭлемент компонента формыИдентификатор компонента, например PROPERTY(name(i)) или имя контейнера.

Для адресации в WebMCP используются дополнительные атрибуты, в том числе lsfusion-form-label, lsfusion-form-window, lsfusion-property, lsfusion-group и lsfusion-row. У <Platform> и usePlatform в React есть свои атрибуты для пользовательского размещения.

Цветовая тема​

Пока включена тёмная цветовая тема, у корневого элемента страницы (<html>) атрибут data-bs-theme имеет значение dark. В этом случае селектор [data-bs-theme="dark"] .board выбирает элементы класса board. При светлой теме атрибут отсутствует или имеет значение light. Атрибут меняется при переключении темы, без перезагрузки страницы.

Расположение компонентов​

Таблица показывает, как правила расположения компонентов формы и опции дизайна соотносятся со свойствами CSS в контейнерах формы с CSS Flexbox.

Дизайн формыСвойство CSS
Коэффициент расширения (flex)flex-grow
Базовый размер вдоль основного направления контейнераflex-basis. Веб-клиент использует значение auto и задаёт размер вдоль этого направления через width или height.
Сжатие вдоль основного направления контейнера до размера меньше базового (shrink)flex-shrink (1 для TRUE, 0 для FALSE)
Переполнение по горизонтали у компонента (overflowHorz) или у ячейки значения (valueOverflowHorz)overflow-x
Переполнение по вертикали у компонента (overflowVert) или у ячейки значения (valueOverflowVert)overflow-y

В контейнерах с расположением по CSS Grid веб-клиент задаёт размеры колонок и строк в grid-template-columns и grid-template-rows. Для дорожек, соответствующих линиям контейнера (lines), lineSize задаёт базовый размер, а lineShrink управляет сжатием. Если базовый размер дорожки не задан, используется min-content. Положительный коэффициент расширения задаёт максимум в единицах fr, например minmax(min-content, 1fr). Если сжатие разрешено, минимум равен 0px, иначе используется базовый размер. Для колонки или строки без положительного коэффициента расширения клиент при разрешённом сжатии использует minmax() с 0px и базовым размером, иначе — только базовый размер.

к сведению

Веб-клиент задаёт ширину колонок таблицы с помощью table-layout: fixed. Для каждой колонки клиент задаёт базовую ширину в отдельной ячейке. У растягиваемой колонки есть вторая такая ячейка. Её ширина в процентах равна доле коэффициента расширения колонки в сумме коэффициентов всех колонок. Заголовок и ячейки значений растягиваемой колонки занимают ширину обеих ячеек.

Классы системных окон и элементов навигатора​

Модуль SystemEvents задаёт эти строки классов для системных окон и элементов навигатора. При выполнении соответствующего условия он добавляет вспомогательные классы после базовых.

Окно или элемент навигатораБазовые классыВспомогательные классы и условия их добавления
logobg-dark-subtleНастольный веб-клиент использует эти классы, если окно не рисует компонент React. Вертикальная панель получает navbar-force-align-start, а при navigatorPinMode[] равном NULL и когда окна не располагает компонент React, ещё и navbar-text-on-hover. Горизонтальная панель получает navbar-auto-icon-font-size.
rootbg-dark-subtle navbar-icon-largeНастольный веб-клиент использует эти классы, если окно не рисует компонент React. Вертикальная панель получает navbar-force-align-start. При любой ориентации добавляется navbar-text-on-hover, если navigatorPinMode[] равно NULL и окна не располагает компонент React.
systembg-dark-subtleВ настольном веб-клиенте всегда добавляется navbar-icon-large, а для горизонтальной панели ещё и navbar-text-hidden. При вертикальной панели, если окно не рисует компонент React, этот клиент добавляет navbar-force-align-start, а при navigatorPinMode[] равном NULL и когда окна не располагает компонент React, ещё и navbar-text-on-hover.
formsbg-body-tertiarydont-show-close-button в мобильном веб-клиенте или когда выполняется dontShowCloseButtonOnInactiveTab[] и окно не рисует компонент React
toolbarbg-body-secondarynavbar-popup-over-selected-hover в настольном веб-клиенте, если навигатор не закреплён целиком (navigatorPinMode[] не TTRUE) и окна не располагает компонент React
logbg-body-secondarynavbar-popup-over-selected-hover navbar-always-hide-unpinned в настольном веб-клиенте, пока окно логов не закреплено (logsPinMode[]) и окна не располагает компонент React
logoActionnavbar-icon-largenavbar-hidden в мобильном веб-клиенте без Bootstrap (useBootstrap[] не выполняется)
toggleNavigatorPinMode—navbar-hidden в мобильном веб-клиенте
Класс CSSДействие в стандартном представлении
bg-dark-subtle, bg-body-tertiary, bg-body-secondaryЗадают фон окна по теме Bootstrap.
navbar-icon-largeУвеличивает значки навигатора.
navbar-text-on-hoverПоказывает заголовки элементов при наведении, когда открыта форма.
navbar-force-align-startВыравнивает кнопки навигатора по началу поперечной оси.
navbar-auto-icon-font-sizeПодбирает размер шрифтовых значков по высоте горизонтальной панели навигации в Chromium и Safari.
navbar-text-hiddenСкрывает заголовки элементов навигатора.
dont-show-close-buttonСкрывает кнопку закрытия на неактивных вкладках форм.
navbar-popup-over-selected-hoverПоказывает элементы окна поверх формы при наведении или после выбора, когда открыта форма.
navbar-always-hide-unpinnedОставляет незакреплённое окно логов свёрнутым при отсутствии взаимодействия, в том числе когда формы закрыты.
navbar-hiddenСкрывает кнопку навигатора.

Загрузка таблиц стилей​

Таблица стилей включается в сборку через импорт CSS в клиентском модуле JavaScript. Отдельный файл .css в resources/web/init загружается автоматически при открытии страницы. Таблицу стилей также можно зарегистрировать для загрузки при инициализации веб-клиента через onWebClientInit[STRING] или загрузить явно с помощью INTERNAL CLIENT.
