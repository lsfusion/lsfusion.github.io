# Class operators

Class operators include the following operators:

* [Classification (`IS`/`AS`)](/Classification_IS_AS.md) — determine whether an object belongs to a class.
* *Signature matching* — determines whether a property can have a value for given objects, judged by the classes of those objects.

### Language[​](#language "Direct link to Language")

The [`ISCLASS` signature matching operator](/Property_signature_ISCLASS.md) tests whether the classes of the arguments match the property's signature.
